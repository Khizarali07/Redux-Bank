# Redux Bank-Account (Course project)

A simple bank account simulation demonstrating Redux (or local state) for transaction handling, balance updates and history.

## Key features

- Add deposit/withdraw transactions
- Transaction history with timestamps
- Balance calculation and simple validation

## Tech

- React (Create React App)
- Redux (if included) or React state

## Run locally

1. Install dependencies: `npm install`
2. Start dev server: `npm start`

## Notes

- If Redux is used, check `src/store.js` and `src/features/` for implementation details.
